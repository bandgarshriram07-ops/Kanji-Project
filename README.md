Kanji Project
Kanji Project is a full-stack Japanese learning web application developed using the MERN stack. The main purpose of this 
project is to help users learn and explore Japanese kanji characters in a simple and user-friendly interface.
Users can search kanji characters and view their meanings, Onyomi readings, and Kunyomi readings.
The application provides organized kanji data for Japanese learners, especially for JLPT preparation.
The project includes authentication and authorization features using JWT and cookies. 
Registered users can securely log in and access protected features. Admin users can manage kanji data with create, update, and delete functionality.
The frontend is built with React and Vite for fast performance and responsive UI design, 
while the backend is developed with Node.js, Express.js, and MongoDB for database management.

Kanji Project は、MERN Stack を使用して開発した日本語学習用のフルスタック Web アプリケーションです。
このプロジェクトの目的は、日本語学習者が漢字を簡単に検索し、意味や読み方を学べるようにすることです。
ユーザーは漢字を検索し、意味、音読み（Onyomi）、訓読み（Kunyomi）を確認できます。
JLPT 学習者向けに、漢字データを分かりやすく整理しています。
このプロジェクトには、JWT と Cookie を使用した認証・認可機能があります。
登録したユーザーは安全にログインでき、管理者ユーザーは漢字データの追加・編集・削除を行うことができます。
フロントエンドは React と Vite を使用し、高速でレスポンシブな UI を実現しています。
バックエンドは Node.js、Express.js、MongoDB を使用して開発しています。

Purpose of Project
The purpose of this project is to improve Japanese language learning by providing an interactive platform for studying kanji. 
It also demonstrates full-stack web development skills including frontend development,
backend API creation, database management, authentication, and authorization.

プロジェクトの目的
このプロジェクトは、日本語学習をより便利にするための漢字学習プラットフォームです。
また、フロントエンド開発、バックエンド API 開発、データベース管理、認証・認可など、フルスタック Web 開発スキルを実践する目的でも開発しました。
